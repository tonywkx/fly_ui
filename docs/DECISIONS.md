# Decisions (settled — don't re-litigate without new facts)

- 2026-09-30 TypeScript only; pnpm workspaces; Biome for lint+format (no ESLint/Prettier).
- 2026-09-30 Dataset `male-cns:v1.0` (brain+VNC in one volume; male-specific neurons for song). CC-BY attribution.
- 2026-09-30 LIF baseline = Shiu et al. 2024 params (see PLAN.md §Reference data); Glu treated inhibitory.
- 2026-09-30 UI motion = motion/react; camera = GSAP; no Anime.js. shadcn/ui base so Kokonut/Bklit registries drop in.
- 2026-09-30 Realtime plots = uPlot + custom canvas raster (Bklit/visx too slow for 60 fps streams).
- 2026-09-30 Fonts: Inter Variable + Geist Mono (PP Neue Montreal is commercial).
- 2026-09-30 Docs/config for Claude written in English (token economy); chat with user in Russian.
- 2026-09-30 No DuckDB-WASM / react-three-fiber (early chat idea): own binary format + vanilla three.js (frame loop outside React). Type-level graph replaces DuckDB queries.
- 2026-09-30 Same TS engine for baked scenarios and live sandbox; Brian2 not used (validate against published results).
- 2026-10-01 Scenario neuron sets: core (anchor types) + extended (types with summed weight ≥500 to key hubs), target 200–2000 neurons; gap-junction links (absent from connectome) go into `overrides` as electrical.
- 2026-10-01 Edge sign from predicted NT: ACh +, GABA/Glu −; NT conf <0.6 or unclear → 0; motor-neuron presynaptic sign → 0. Unclear signs are resolved only by explicit `overrides` in the scenario JSON.
- 2026-10-01 Scout manifests keep type-level edges with weight ≥50 (CSR prune threshold is decided in 1.7, not here).
- 2026-10-01 Extended-set thresholds differ per circuit on purpose (density differs): escape ≥500 → 1254 neurons; sugar ≥200, types ≤100 neurons only (BM_InOm excluded) → 945; song ≥1200 → 1703.
- 2026-10-01 Escape: GF = DNp01. Overrides DNp01→TTMn and DNp01→PSI electrical; DNp01→GFC2 optional sim boost.
- 2026-10-01 Sugar: stimulus = all 40 BM_Taste (sugar-GRN proxy; male-cns has no Gr5a/Gr64f types); PER readout = MN9. Sign ambiguity (GABAergic GRN→MN9 routes) is deferred: Phase 3 test "BM_Taste stimulus → MN9 spikes" (anchor Shiu 2024); if it fails, add an override or fall back to stimulating DNge062.
- 2026-10-01 Song: P1 = pC1_* family (9 core types). Readout pIP10 → vPR9/vMS11/TN1a → wing MNs + DLMn/DVMn. maleSpecific flag from fruDsx (≠ fru_low).
- 2026-10-01 Data format: one `manifest.json` (zod, `formatVersion` must match exactly, else FormatVersionError → re-bake) + binary chunks `FLYD` container (16 B header, 12 B/section table, LE, 4-byte aligned sections; dtypes ≤4 B only, no Float64). Chunk tier `first-frame | lazy` drives the 15 MB budget.
- 2026-10-01 Skeleton model: soma = largest-radius node with SWC type=1, else largest radius overall; soma component rerooted at soma and BFS-renumbered (soma = 0, parent[i] < i); disconnected fragments kept as extra roots, not dropped.
- 2026-10-01 Skeletons chunk: sections offsets u32 (m+1) | bodyId u32 lo,hi | pos u16 (bbox-quantized) | radius u16 (whole nm) | parent i32 (local, -1 root); SWC type dropped (neuPrint has no compartments). Path distance is recomputed on decode, not stored. `simplify` = RDP (segment distance) on unbranched runs; roots/branches/leaves always kept.
- 2026-10-01 Skeleton fetch: `GET /api/skeletons/skeleton/{dataset}/{bodyId}?format=swc` (dataset NOT url-encoded, else 403); raw SWC cached as `data/cache/skeletons/{id}.swc` (validated with parseSwc, atomic tmp+rename), no-skeleton bodies → `{id}.missing` marker; concurrency 8. All 3605 scenario bodies ≈ 400 MB raw.
- 2026-10-01 Background cloud: cable-uniform samples (`sampleCable`) from a seeded random 5000 of all 176422 `:Neuron` bodies (`pnpm pull --random=5000`, seed 1); scenario neurons are NOT mixed in (keeps density CNS-uniform). Spacing 300 source units → ~2.16M points, shuffled into disjoint tiers 200k / 600k / 1.2M (LOD k = tiers 0..k; lod0 1.14 MB first-frame, rest lazy). `cloud` chunk = one section pos u16 (3N, bbox-quantized), one file per tier.
- 2026-10-01 male-cns SWC coordinates are 8 nm voxels, not nm (cloud bbox ≈ [2.5k,5k,8.7k]–[93.6k,69.5k,134.5k] ≈ 0.73×0.52×1.0 mm). Manifest bbox unit is settled at bake (1.8).
- 2026-10-02 Neuropils: shells (`CentralBrain`, `Optic(L/R)`, `CV`, `VNC`, ≤15k tris each, first-frame) + 139 primary ROIs minus `*-unspecified` (≤2k tris each, lazy), welded then meshoptimizer-simplified; one shared bbox = shells bbox + 100. `neuropil` chunk: pos u16 (bbox-quantized) | index u16 (local per mesh, ≤65535 verts) | ranges u32 (vertStart, vertCount, indexStart, indexCount) | names UTF-8 JSON; decoder merges into one geometry (global u32 index + ranges). Normals computed on the client.
- 2026-10-02 Connectivity: CSR prune threshold weight ≥5 per neuron pair (FlyWire/Shiu 2024 convention; ≈7M of ≈28M edges, ≈73% of synapses), same threshold for scenario subgraphs and the full graph. Sign lives per neuron (Dale), not per edge: `meta.sign` i8, edge `weight` u16 = synapse count, signed weight = sign[pre]·weight. Sign from `consensusNt` with conf = `celltypePredictedNtConfidence ?? predictedNtConfidence`: ACh +, GABA/Glu/**histamine** − (HisCl), conf <0.6 / unclear / modulators / `vnc_motor`·`cb_motor` → 0. Row order = (type, bodyId), untyped last. region = primary ROI with max pre+post in `roiInfo`.
- 2026-10-02 `graph` chunk: offsets u32 (n+1) | cols u32 delta-coded within each row | weight u16; outgoing only (incoming built client-side). `meta` chunk: bodyId u32 lo,hi | type u16 | region u16 | class u8 | superclass u8 | nt u8 | sign i8 | ntConf u8 | flags u8 (bit0 maleSpecific) | somaSide u8 | strings UTF-8 JSON; 0xFF/0xFFFF = absent. Scenario overrides (electrical etc.) are not in the graph chunk (Phase 3).
- 2026-10-02 Bake (`pnpm bake`, offline from `data/cache` + `data/scout`): manifest v2 adds `unitNm: 8`; coordinates stay in source units (8 nm voxels). One shared bbox for every chunk = union(shells, regions, cloud, scenario skeletons) + 100, re-encoded from float sources (no double quantization). Budget = raw bytes of first-frame chunks ≤ 15 MiB. First-frame: neuropil shells, cloud lod0, graph+meta of all scenarios, skeletons of the default scenario only (`escape`, listed first in `scenarios`); everything else lazy (incl. other scenarios' skeletons, typegraph pruned at type-edge weight ≥10, meta-full, graph-full). Hero skeletons simplified with RDP ε=125 units (1 µm): branch points + leaves floor ≈ 630k nodes/escape, so ε alone cannot fit all three scenarios. Chunk file = `<id>.bin`, flat in `public/data/`.
- 2026-10-02 Web: NT colours live in `apps/web/src/ui/palette.ts` (keyed by `Nt` from `@fly/data`, linear rgb for shaders) and are mirrored in `theme.css` `--color-nt-*`; `palette.test.ts` enforces sync. Snap readiness = `AppStore.pending` flags (`waitFor`/`markReady`), `window.__snapReady` only via `when(app.ready)` in `main.tsx`, never from components.
- 2026-10-02 Scene: three imported from `three/webgpu` only (one instance), OrbitControls from `three/addons` (GSAP will drive it later). Scene units = µm, origin = CNS bbox centre, y up (source y,z negated). Chunk decode always in a comlink Worker pool; payloads stay out of MobX (`DataStore` plain Map + observable `loaded`/`ready`).
- 2026-10-02 Hero neurons: one instanced screen-facing quad per skeleton segment (not Line2), additive, no depth write, drawn after background (renderOrder 1). Per-segment data = `buildSegments` stride-12 Float32; per-neuron state (activity, highlight) is looked up by `row` (= meta/graph row) in the shader, never baked into the segment buffer. Colour by NT via a `uniformArray` palette (WebGL2-safe).
- 2026-10-02 Activity → GPU: per-row "last spike time" (sim ms) in an R32F DataTexture (width 256) sampled by `row` in the vertex shader; the wave is derived in-shader from age × speed vs soma distance. Fake BFS now, the live sim (3.4) writes the same array. Post: `RenderPipeline` + bloom (threshold ≥1, HDR fronts only) + AgX tone map.
- 2026-10-02 Debug colour modes (`?debug=soma-dist|id|nt|region`) draw hero ribbons opaque + depth-tested with neurons isolated and activity off; only the live/wave view is additive. soma-dist ramp is a fixed 0..500 µm scale, not data max.
- 2026-10-02 Quality: presets live only in `scene/quality.ts`; MSAA off on every preset (measured costliest); dust capped at lod0 until dense dust is made cheap (backlog). Pixel ratio, bloom and dust tiers switch live from `app.quality` via MobX reactions; URL/snap pins the preset, otherwise `FpsGuard` may step it down.
- 2026-10-02 Sim integrator: fixed dt=0.1 ms (Brian2/Shiu) with the exact exponential step of the linear (u, g) pair, not a pure event-driven solver (threshold crossing has no closed form). Only the active set (|u| or |g| > 1e-4 mV, or refractory) is integrated; quiet neurons snap to rest. Uniform delay → FIFO ring of (due step, pre). Refractory = v held at reset, g keeps decaying (Brian2 `unless refractory`). v/g are Float64 (f32 stalls the decay near −52 mV). `inject` = instant g kick, no delay.
